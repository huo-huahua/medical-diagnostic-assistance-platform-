# 归档知识文件

本目录存放**已停止加载**的知识库文件，保留以供追溯，不影响检索。

`sources/` 是唯一被加载的目录（`settings.knowledge_dir`），本目录下的文件不会被读取。

## 归档记录

### `breast_basic_zh.txt`

- **归档时间**：2026-10-04
- **归档原因**：内容与 `sources/breast_cancer_zh.md` 高度重叠（同样覆盖早期症状、诊断方法、风险因素、治疗、预防、术后康复六个主题），且标题为英文、正文为英文。
- **为什么必须移出**：重复条目会在向量检索中相互竞争，使同一问题召回两条近乎同义的结果，既浪费 citation 名额，也降低了不同信息条目的曝光机会。此外该文件标题为英文，与中文提问的词面重叠检查不匹配，容易在"语义相似但词面不重叠"的门控中被判为弱相关。
- **处置方式**：未删除，仅移出加载目录。若后续需要英文知识条目，应新建独立的英文知识文件并调整分块与门控策略，而不是保留这份重复内容。
